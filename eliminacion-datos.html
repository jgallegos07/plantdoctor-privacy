Eliminación de datos de PlantDoctor

```

En PlantDoctor puedes eliminar tus diagnósticos y los datos asociados desde la propia aplicación.

Cómo eliminar tus datos

  1. Abre PlantDoctor.
  2. Accede a Mis diagnósticos.
  3. Selecciona el diagnóstico que deseas eliminar.
  4. Utiliza la opción de eliminación disponible en la aplicación.

Qué datos se eliminan

Al eliminar un diagnóstico, se elimina el diagnóstico correspondiente y los datos asociados tanto del dispositivo como del servidor utilizado para prestar el servicio de análisis.

Las fotografías utilizadas para realizar el análisis se procesan temporalmente y se eliminan después de completar el procesamiento.

Conservación de datos

Los resultados de los diagnósticos se conservan en el servidor hasta que el usuario los elimina desde la aplicación.

Los datos almacenados localmente en el dispositivo se eliminan cuando el usuario elimina el diagnóstico correspondiente desde la aplicación.
```
